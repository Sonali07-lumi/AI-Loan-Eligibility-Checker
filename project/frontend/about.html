About, privacy & security

How it works

FINOVA applies fixed, published rules to the numbers you enter: income-to-obligation ratios, credit bands, and the reducing-balance EMI formula. When configured, the backend also asks Claude to write a plain-language explanation of the rule-based result. Nothing here is a lender decision.

Each tool shows the assumptions behind its estimate, such as the indicative interest rate used in the loan checker.

Privacy

  • Only the fields each tool needs are requested — no names, ID numbers, or bank details.
  • Your currency choice and recent results are stored in this browser; a copy is saved to the backend's Google Sheet only if the server has Sheets configured.
  • The Anthropic API key and Google service-account credentials live only on the server and are never sent to the browser.

Disclaimer: This platform provides educational estimates and AI-generated financial insights. Results are not official loan approvals, credit-bureau scores, or professional financial advice.
